About

Hi! My name is Kashish and I'm a Computer Science student at the University of Guelph with a minor in Mathematics. I'm deeply interested in algorithms, data structures, and mathematical logic. I like turning analytical problems into clean, working software.

I've worked across C, Python, Java, JavaScript, and Fortran, Ada, and COBOL. As an IT Systems Assistant with the Ontario government, I built reports in Power BI and maintained a legacy web application using Angular, JavaScript, and XML.

Outside of code, I make art, which you can see in the Art section!

A Sokoban-style puzzle game where players explore connected rooms, push obstacles, and collect treasure. The game engine is written in C and wrapped in Python, with a terminal interface built on the Model–View–Controller pattern and tests on both sides of the language boundary.

Java · Multithreading · Swing · Reflection · Serialization

A multi-threaded greenhouse simulator with a graphical control panel. Scheduled events run concurrently and share state safely through a central controller, with support for suspend and resume and for saving and restoring the system's state.
